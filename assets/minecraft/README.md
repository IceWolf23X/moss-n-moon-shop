# Supplied Bare Bones assets

Imported from the three resource-pack archives supplied for this repository, with base-first, missing-path precedence. Bare Bones 1.21.11 includes compatible overlays for pack format 75. X Updated and Extra fill gaps only.

Original metadata and SHA-256 checksums are recorded in `manifest.json`. The base pack is Bare Bones (https://www.planetminecraft.com/texture-pack/bare-bones/); the supplied Extra metadata credits Colonel260. X Updated metadata is retained as supplied. These assets remain the work of their respective creators; importing them does not make them original artwork of this site. The supplied archives did not include separate license files.

`textures/`, `models/`, `blockstates/` and `items/` preserve the supported supplied files unchanged. `previews/` contains generated static PNG frames. `rendered/` contains the primary 256×256 inventory-model renders generated offline by CoreChatX, with its own provenance and checksum manifest. Vanilla assets used to fill model/texture gaps are checksum-verified and kept in the external build cache; only the finished render PNGs are committed. See the repository README for reproduction commands and supported catalog IDs.
